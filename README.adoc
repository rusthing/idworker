= idworker

A high-performance distributed ID generator library for Rust, implementing Snowflake algorithm variants with multiple optimization modes for different performance requirements.

== Overview

`idworker` is a Rust library that provides efficient, distributed unique ID generation. It's based on the Snowflake algorithm but includes several optimizations for different performance scenarios. The library is designed for use in distributed systems where globally unique identifiers are needed.

== Features

* Multiple ID generation algorithms:
** Standard Snowflake implementation
** Optimized Fast ID Worker variants
* Three performance modes:
** `Normal` - Standard performance mode
** `Faster` - High-performance optimized mode
** `Fastest` - Maximum performance mode
* Thread-safe ID generation
* Configurable parameters (timestamps, data centers, nodes)
* Comprehensive benchmark tests
* Zero dependencies in production code

== Installation

Add this to your `Cargo.toml`:

[source,toml]
----
[dependencies]
# IdWorkerGenerator / setup_id_worker / next_id 在 utils feature 下
idworker = { version = "1.4.0", features = ["utils"] }
----

== Usage

=== Basic Usage

[source,rust]
----
use idworker::{IdWorkerConfig, IdWorkerGenerator, Mode};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let config = IdWorkerConfig::builder()
        .mode(Mode::Normal)
        .epoch(1609459200000)      // 基准时间戳（毫秒）
        .data_center(0)            // 数据中心编号
        .node(1)                   // 节点编号（同一 epoch 下每个实例必须不同）
        .build()?;

    let id_worker = IdWorkerGenerator::generate(config)?;
    let id = id_worker.next_id()?;
    println!("Generated ID: {id}");
    Ok(())
}
----

NOTE: `node` 的类型是 `Option<u8>`：不设置时为 `None`，生成器按 0 处理。框架层
（如 robotech）用 `None` 表示"由框架自动分配"，因此 **0 是一个合法且可独立使用的
节点编号**，不会被当作特殊标记。

NOTE: 位宽预算：`data_center_bits + node_bits + sequence_bits` 之和越大，留给时间戳的高位越少。
当前时间戳约占 45 位，主键按 i64 存储时三者之和不应超过 18 位（默认 0 + 4 + 12 = 16）。
超出后生成的 ID 会越过 `i64::MAX`，落库为负数。

=== Performance Modes
[source,rust]
----
// Normal - 每次取当前时间戳，多实例/重启安全（分布式部署只用这个）
let normal = IdWorkerGenerator::generate(
    IdWorkerConfig::builder().mode(Mode::Normal).build()?
)?;

// Faster - 初始化时取一次时间戳，之后纯自增；仅适合单进程
let faster = IdWorkerGenerator::generate(
    IdWorkerConfig::builder().mode(Mode::Faster).build()?
)?;

// Fastest - 序列号用尽后直接给时间戳 +1，可能跑到未来；仅适合单进程
let fastest = IdWorkerGenerator::generate(
    IdWorkerConfig::builder().mode(Mode::Fastest).build()?
)?;
----

== Thread Safety

All ID generators are thread-safe and can be used across multiple threads:

[source,rust]
----
use idworker::{IdWorkerConfig, IdWorkerGenerator, Mode};
use std::thread;

// generate 返回的是 Arc<dyn IdWorker>，可直接跨线程共享
let id_worker = IdWorkerGenerator::generate(
    IdWorkerConfig::builder().mode(Mode::Normal).build()?
)?;

let mut handles = vec![];
for _ in 0..10 {
    let worker = id_worker.clone();
    handles.push(thread::spawn(move || worker.next_id()));
}
----
